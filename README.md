# 🌤️ Clima Tempo

Aplicação web desenvolvida para consultar informações climáticas de cidades em tempo real, utilizando tecnologias fundamentais do front-end.

🔗 **Acesse o projeto:**  
https://elisangelaamaral9-hue.github.io/clima-tempo/

---

## 📌 Visão Geral

O **Clima Tempo** é um projeto criado com foco no aprendizado e na prática de conceitos essenciais do desenvolvimento web, como consumo de APIs, manipulação do DOM e construção de interfaces simples e funcionais.

A aplicação permite que o usuário pesquise por uma cidade e visualize informações climáticas de forma clara e objetiva.

---

## ⚙️ Funcionalidades

- 🔍 Busca de clima por nome da cidade  
- 🌡️ Exibição de informações climáticas relevantes  
- 🖥️ Interface simples e intuitiva  
- 📱 Estrutura preparada para evolução responsiva  

---

## 🛠 Tecnologias Utilizadas

- **HTML5** — Estrutura semântica da aplicação  
- **CSS3** — Estilização e layout  
- **JavaScript (ES6+)** — Lógica da aplicação e consumo de API  
- **GitHub Pages** — Deploy do projeto
