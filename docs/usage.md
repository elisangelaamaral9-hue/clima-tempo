# Uso

1. Abra `index.html` no navegador.
2. Digite a cidade e clique em "Buscar".

Observações:
- A aplicação usa as APIs públicas da Open-Meteo sem chave.
- Recomendado usar navegador moderno (Chrome/Edge/Firefox).

Notas e acessibilidade:
- O campo de busca possui rótulo acessível e o botão é desabilitado enquanto os dados são carregados.
- Mensagens de erro/estado usam `aria-live` para leitores de tela.

Se ocorrerem problemas de CORS ao abrir o arquivo diretamente, execute um servidor estático local (veja README).
